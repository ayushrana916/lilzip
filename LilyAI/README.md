# L.I.L.Y. AI — Voice Assistant for Android

**Logical Intelligent Lifelike Youth** — Your personal AI assistant powered by Claude.

---

## Features
- 🎙️ Wake word "Hey Lily" — works even on lock screen
- 💬 Send WhatsApp messages by voice
- 📞 Call contacts by voice  
- 🔍 Search the web, YouTube, Maps
- 📖 Reads your real phone contacts
- 📋 Read incoming WhatsApp/SMS notifications
- 📱 Open any app by voice
- ⏰ Set alarms and timers
- 🔦 Control torch, volume
- 🤖 Full AI powered by Claude

---

## Setup Steps (on your Vivo Y200)

1. Get API key from: https://console.anthropic.com
2. Install the APK from GitHub Actions
3. Open app → Enter API key → Save
4. Grant all permissions
5. Tap "ACTIVATE LILY"
6. Say "Hey Lily" anywhere!
